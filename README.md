🎬 MovieCity

Uma landing page de filmes desenvolvida com React e Vite.

📌 Sobre o projeto

O MovieCity é um projeto front-end criado para praticar desenvolvimento web com React, organização de componentes e estilização com CSS.

🚀 Tecnologias utilizadas
React — construção de interfaces.
Vite — ambiente de desenvolvimento e build.
JavaScript — lógica da aplicação.
CSS — estilização da interface.
npm — gerenciamento de dependências.
⚙️ Como executar o projeto
Pré-requisitos
Node.js
npm
1. Clone o repositório
git clone URL_DO_SEU_REPOSITORIO

2. Entre na pasta do projeto
cd 01_landinpage

3. Instale as dependências
npm install

4. Inicie o servidor
npm run dev


Abra no navegador o endereço exibido no terminal, geralmente:

http://localhost:5173/
