🎬 MovieCity

Uma landing page de filmes desenvolvida com React e Vite.

📌 Sobre o projeto

O MovieCity é um projeto front-end criado para praticar desenvolvimento web com React, organização de componentes e estilização com CSS.

🚀 Tecnologias utilizadas
React — biblioteca para construção de interfaces.
Vite — ferramenta de desenvolvimento e build.
JavaScript — linguagem de programação.
CSS — estilização da interface.
npm — gerenciamento de dependências.
⚙️ Como executar o projeto
Pré-requisitos
Node.js instalado.
npm instalado.
Instalação
Clone o repositório:
git clone URL_DO_SEU_REPOSITORIO

Entre na pasta do projeto:
cd 01_landinpage

Instale as dependências:
npm install

Inicie o servidor de desenvolvimento:
npm run dev

Acesse no navegador o endereço exibido no terminal, geralmente http://localhost:5173/.

Para gerar os arquivos de produção, execute:
